# 向零件库追加新模块

看到论文或开源里比较新的模块时，按这条入库，不要把代码追加回原来的整份 `模块.md`。

## 步骤

1. 在 `modules/` 下新增一个文件，文件名用小写+下划线，例如 `msda.py`。
2. 文件顶部 docstring 写清：全称、论文/年份、做什么、输入输出约定、依赖、已知限制。
3. 实现放在独立 `nn.Module` 里。能加 `if __name__ == "__main__"` 的最小 Forward 示例更好。
4. 在 [catalog.md](catalog.md) 增加一行，填完整表头，不要只写模块名。
5. 若实现未核对过（复制来的、缺依赖、接口不是 NCHW），`状态` 填 `需核对` 或 `不可用`，Skill 筛选时会跳过或先警告。

## catalog 字段

| 字段 | 写什么 |
|------|--------|
| id | 短名，与文件名一致 |
| 类型 | Channel / Spatial / Multi-scale / Context / Fusion / Lightweight / Token-attn 之一，可多选 |
| 同shape | 是 = 输入输出空间尺寸和通道都不变，才适合当即插头 |
| 维数 | 2D / 3D / token |
| 依赖 | 仅 torch，或 timm / mmcv / einops 等 |
| 优先插入 | Bottleneck / Skip / Encoder 深层 等 |
| 状态 | 可用 / 需核对 / 不可用 |
| 备注 | 和谁功能重复、不适合什么任务 |

## 不要做的事

- 不要把新模块写进实验方法文档。实验方法只记录划分、训练协议、消融表。
- 不要一次把新模块和旧模块一起塞进网络。
- 不要把未跑过 Forward 的代码标成「可用」。
